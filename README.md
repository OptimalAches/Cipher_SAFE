# 🔐 Cipher_SAFE — Password Manager

Cipher_SAFE is a lightweight, client-side password manager built using **React (Vite)** and **Tailwind CSS**.  
It allows users to securely store, edit, and delete website credentials directly in the browser using **LocalStorage**.

---

## 🚀 Features
- Add, edit, and delete login credentials  
- Browser-based storage using **LocalStorage**  
- Real-time notifications using `react-toastify`  
- Unique IDs generated via `uuid`  
- Clean and responsive UI using Tailwind  
- Zero backend — works fully offline  

---

## 🛠️ Tech Stack
- **React (Vite)**
- **Tailwind CSS**
- **LocalStorage**
- **react-toastify**
- **uuid**
- **Font Awesome**
